Selected work click a project to open it

  • A natural-language search and reasoning system for long egocentric videos. LaViLa video-language embeddings and FAISS retrieval connect a question to the visual evidence that answers it.

    Instead of relying only on event captions, it retrieves the best-matching frames first, then reconstructs the surrounding events. A Streamlit interface shows matching frames, similarity scores and interactive timelines.

    Tested across five sessions and more than 13,800 indexed frames from a processed EPIC-KITCHENS subset.

    Python · PyTorch · LaViLa · FAISS · Hugging Face Transformers · Llama / Ollama · Streamlit

  • A full-stack visual inspection system with inspection history, anomaly heatmaps and a model registry that selects the deployed model version at runtime.

    I compared autoencoder, ResNet18, PatchCore and EfficientAD approaches on MVTec AD 2 and selected EfficientAD. The decision threshold uses validation-only statistics to avoid test-label leakage.

    EfficientAD reached 0.850 AUROC. A Docker Compose setup connects the API, PostgreSQL, MLflow, Prometheus and Grafana, and the CI pipeline caught a regression before release.

    Python · TypeScript · PyTorch · FastAPI · PostgreSQL · React · MLflow · Docker · Alembic

  • A real-time conversational system that connects speech recognition, context-aware LLM dialogue and speech synthesis.

    I diagnosed the transcription component to cut waiting time, then built a small evaluation framework around response relevance and response time to guide improvements.

    Transcription latency went from 20–30 seconds down to 2–4 seconds.

    Python · Claude API · faster-whisper · SpeechRecognition · spaCy · pyttsx3
